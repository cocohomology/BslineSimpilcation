# Session 0008 — Degen Revisited as a Metric-Design Method

Date: 2026-09-13

## Objective

After Session 0007 broke the usefulness of the global-curvature product, revisit Degen 1992 with one narrow question:

> Should we inherit Degen's normal distance directly, or learn from the way he constructs the metric?

## Result

The more important inheritance is methodological:

1. construct a geometric neighbourhood of the reference;
2. restrict to an admissible class with a one-to-one correspondence;
3. derive the deviation field from that correspondence;
4. only then apply a norm;
5. prove its relation to Hausdorff and its regular dependence on approximation parameters.

This changes the direction of the present project. The next geometric object should not be guessed as another norm of synchronized Green error. Instead we should construct a nonlinear local normal branch first.

For space curves define
\[
F(t,u)=(\widetilde C(t)-C(u))\cdot C'(u).
\]
A normal branch satisfies \(F(t,\sigma(t))=0\). For cubic reference spans, \(F\) has degree at most five in \(u\). The implicit-function denominator is
\[
\|C'(u)\|^2-r\cdot C''(u),
\]
which in arc length becomes \(1-r\cdot\kappa_{\rm vec}\). This is the direct space-curve analogue of Degen's curvature-radius nondegeneracy.

A major synthesis was obtained:
\[
\sigma(t)-t\approx-\frac{E\cdot C'}{\|C'\|^2},
\]
so the Session-0005 first-order tangential quotient is exactly the first Newton/IFT linearization of the nonlinear normal-projection equation.

If a candidate is a one-to-one normal graph in a tube where each matched reference point is the unique nearest point, then the normal deviation satisfies
\[
d_H=\|r\|_\infty.
\]
Thus the crucial difficulty is admissibility/branch construction rather than the final use of the sup norm.
