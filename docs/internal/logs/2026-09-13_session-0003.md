# Session 0003 — Fixed-Endpoint Green Operator

Date: 2026-09-13

## Objective

> For endpoint-preserving reconstruction, derive and review the exact operator mapping second-derivative error \(e=C''-\widetilde C''\) to positional error \(E=C-\widetilde C\).

Assume
\[
E''=e,\qquad E(a)=E(b)=0.
\]

## Main result

With \(L=b-a\),
\[
E(t)=\int_a^b K_D(t,s)e(s)\,ds,
\]
where
\[
K_D(t,s)=
-\frac{(\min\{t,s\}-a)(b-\max\{t,s\})}{L}.
\]

The kernel is symmetric, negative in the interior, zero at the endpoints, and has the expected \(L^2\) scaling under interval normalization.

Define
\[
N_G(e)=\|G_De\|_\infty.
\]
Then under the fixed-endpoint gauge
\[
N_G(e)=\|C-\widetilde C\|_{\infty,\mathrm{sync}}.
\]
Since synchronized parameters provide a valid correspondence in both directions,
\[
d_H(\operatorname{Im}C,\operatorname{Im}\widetilde C)\le N_G(e).
\]

Detailed derivation: `docs/internal/derivations/fixed_endpoint_green.md`.

## Structural interpretation

For fixed \(t\), \(-K_D(t,\cdot)\) is a positive piecewise-linear tent weight. Thus the Green operator preserves:
- sign/vector cancellation in \(e\);
- location of second-derivative error;
- global coupling caused by endpoint preservation.

A single global \(L^p\) value destroys part of this information before positional effect is computed.

Important caution: the kernel itself is one-signed. Any cancellation comes from \(e\), not from oscillations of the kernel. Therefore “Green norm is tighter than \(L^p\)” is not accepted as a blanket theorem yet; it must later be quantified.

## Unexpected useful observation

The result is partly a rewrite of synchronized positional error, but the rewrite exposes low-degree structure:
- \(e\) is PL;
- \(G_D\) is linear;
- \(N_G\) is convex in \(e\);
- \(E=G_De\) is piecewise cubic.

This suggests that exact/certified evaluation of \(N_G\) may be far cheaper than direct curve-to-curve Hausdorff computation.

Because of that observation, the roadmap was changed: PL-specific direct evaluation of \(N_G\) is now scheduled before deriving the full table of sharp classical \(L^p\) operator constants.

## Failed/rejected formulations

Rejected as too strong:

> “The Green operator already fixes the bad-parametrization problem.”

False. \(N_G\) is exactly synchronized parameter error, hence still parameterization-sensitive.

Also rejected as premature:

> “Green error is always substantially smaller than any \(L^p\) measure.”

This has not been proved. The correct current statement is that the Green operator retains information that global \(L^p\) compression discards; whether that produces materially better candidate ranking remains to be tested/proved.

## Correctness review

Checked:

- scaling under \([a,b]\to[0,1]\);
- compatibility with jump-discontinuous PL \(e\);

Confidence: high for the operator identity and the Hausdorff upper bound.
