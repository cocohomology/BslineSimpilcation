# Session 0015 — Side study: Hausdorff distance versus differentiation/integration

Date: 2026-09-14.

## Objective

Temporarily pause the main global-stitching task and directly answer a geometric question:

> If two curve images are close in Hausdorff distance, are their derivative curves or integral curves necessarily close? Under what additional assumptions can one obtain quantitative control, and what are the natural constants/scales?

This is a side branch, not a main-line pivot.

## Main conclusions

1. **Hausdorff distance alone is too weak.** It forgets parameterization, traversal order, multiplicity, and speed. Identical image sets can have arbitrarily different derivative vectors and antiderivative curves.

2. **Even tangent directions are not Hausdorff-stable without regularity.** A graph perturbation of amplitude `1/n` and frequency `n` converges in Hausdorff distance to a line while retaining order-one tangent-angle oscillation.

3. **Uniform curvature bounds recover first-derivative stability only after a correspondence is fixed.** For synchronized positional error `||E||∞<=eps` and `||E''||∞<=M`, an interior interpolation estimate gives

   `||E'|| <= sqrt(2 M eps)`.

   For synchronized arc-length curves with curvature bounded by `K`, this becomes

   `||T-Ttilde|| <= 2 sqrt(K eps)`

   away from boundary effects.

4. **Curvature itself is not controlled by Hausdorff distance plus a curvature bound.** The example `y_n=n^{-2} sin(nx)` has Hausdorff error `O(n^{-2})`, tangent error `O(n^{-1})`, but order-one curvature oscillation. Thus no inverse control of the project variable `q=C''` from Hausdorff error should be expected under the present assumptions.

5. **Integration is stable once order/correspondence is fixed.** One integration gives an `L` factor. The project’s fixed-endpoint double-integration bound remains the exact operator estimate

   `||C-Ctilde||∞ <= (L^2/8) ||C''-Ctilde''||∞`.

6. **Reach/local feature size is the natural geometric regularity scale.** Positive reach controls both local curvature and competing remote projections. Standard manifold geometry gives tangent variation inside one positive-reach curve, and Hausdorff-to-tangent reconstruction naturally has square-root scale `O(sqrt(eps/tau))` when a reach lower bound `tau` and a suitable local correspondence are available.

7. **The current normal-branch machinery is better understood as a Fréchet-style lift.** Hausdorff compares sets only; a globally stitched monotone normal branch supplies order. If `sigma` is a homeomorphism onto the reference parameter interval, then

   `d_F <= max_t ||Ctilde(t)-C(sigma(t))||`,

   hence the same bound controls symmetric Hausdorff distance. This directly clarifies why the current main-line global stitching problem matters.

## Goal alignment

The side study does not replace the current verification architecture. Instead it explains its asymmetry:

`q-error -> integration -> positional error -> ordered correspondence -> geometric acceptance`

is mathematically stable, while the reverse direction from Hausdorff geometry back to `q=C''` is not.

Therefore the project should **not** spend time seeking a two-sided equivalence between Hausdorff distance and a second-derivative norm in the present cubic C1 model.

## Main-line consequence

Return to Session-0014’s active question after this side branch:

> certify when local monotone normal branches stitch into one global order-preserving correspondence (or decide that two directed correspondences are cleaner).

The present side result strengthens the motivation: global stitching is exactly the missing step that upgrades setwise Hausdorff geometry to an ordered Fréchet-like relation on which differential reasoning becomes meaningful.
