# Session 0005 — Tangential Reparameterization in Arc Length

Date: 2026-09-13

The previous roadmap informally wrote \(\widetilde C=C+E\), which reverses this sign. This session fixes the convention and uses

## First attempt and improvement

A direct shift in the original parameter,
\[
\phi(t)=t+\eta(t),
\]
can cancel the tangential component to first order, but its Taylor remainder involves \(\|C''\|\). That is unsatisfactory because \(C''\) includes tangential acceleration caused purely by parameter speed: even a geometrically straight line can have large \(C''\) under a bad parameterization.

The better formulation uses reference arc length.

Let \(s\) be arc length on regular \(C\), let \(\gamma(s)\) be the unit-speed reference, \(T=\gamma_s\), and let
\[
K=\operatorname*{ess\,sup}\kappa
\]
be the reference curvature bound.

Pull the candidate displacement to this coordinate:
\[
\Delta(s)=\widetilde C(t(s))-C(t(s)).
\]
Define the signed tangential displacement
\[
\delta(s)=\Delta(s)\cdot T(s)
\]
and the reference matching
\[
\rho(s)=s+\delta(s).
\]

## Main theorem/result

If the endpoints agree and
\[
\boxed{
\|D_sE\|_\infty+K\|E\|_\infty<1,
}
\]
then \(\rho\) is an orientation-preserving homeomorphism of the complete arc-length interval.

The unit-speed Taylor remainder satisfies
\[
\|\gamma(s+\delta)-\gamma(s)-T(s)\delta\|
\le \frac K2\delta^2.
\]
Therefore, writing \(P_NE\) for the normal projection of the canonical error,
\[
\boxed{
 d_H(\operatorname{Im}C,\operatorname{Im}\widetilde C)
\le d_F^+(C,\widetilde C)
\le
N_{G,\perp}(e)+\frac K2N_{G,\parallel}(e)^2,
}
\]
where
\[
N_{G,\perp}(e)=\sup_t\|P_{N(t)}E(t)\|,
\qquad
N_{G,\parallel}(e)=\sup_t|E(t)\cdot T(t)|.
\]
In particular,
\[
\boxed{
 d_H\le N_{G,\perp}(e)+\frac K2N_G(e)^2.
}
\]

This is a finite certified inequality, not just a formal first-order expansion.

Detailed derivation: `docs/internal/derivations/arc_length_tangential_quotient.md`.

## Interpretation

This is the first rigorous geometry-aware bridge in the project:
- normal synchronized error enters at first order;
- tangential synchronized error is removable to first order;
- its remaining contribution is quadratic and weighted by geometric curvature;
- the bound is safe for Hausdorff distance whenever the induced matching remains monotone.

Using arc length is essential conceptually: it replaces the parameter-sensitive \(\|C''\|\) remainder by curvature.

## Counterexample / sanity review

### Straight line
For \(K=0\), a monotone endpoint-preserving purely tangential perturbation gives \(N_{G,\perp}=0\) and the bound returns \(d_H=0\), even if the original parameter speed is highly nonuniform.

### Curved pure reparameterization
If \(\widetilde\gamma(s)=\gamma(s+\zeta(s))\), the images are identical, but the present bound is generally only \(O(K\zeta^2)\), not exactly zero. Thus this construction removes first-order parameterization error but is not fully reparameterization-invariant.

### High curvature
The quadratic correction grows with \(K\). This is geometrically meaningful: tangential sliding on a tightly curved region produces a second-order normal chord deviation.

## Correctness review

Checked:

- monotonicity condition via \(\rho'=1+\delta'\);
- remainder for either sign of \(\delta\);
- crossing cubic knots using Lipschitz continuity of the unit tangent;
- dimensions of the curvature remainder;
- straight and curved reparameterization tests.

Confidence: high for the local theorem.

Novelty is not claimed; the point is its integration into the D2/Green simplification framework.

## Goal-alignment review

Strongly aligned. The main weakness after Session 0004 was synchronized parameter dependence. This result shows that the dominant tangential part can be quotiented out locally without immediately solving a full two-parameter Hausdorff/Fréchet problem.
