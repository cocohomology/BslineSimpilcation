# Session 0007 — Adversarial Review Round 1

Date: 2026-09-13

## Objective

Attack the current geometry-aware bound rather than extend it.

The bound under review was
\[
d_H\le N_{G,\perp}+\frac K2N_{G,\parallel}^2,
\]
with an explicitly certified orientation-preserving arc-length correspondence.

The purpose was to determine whether remaining conservatism is mild, structural, or fatal for CAD simplification.

## Main negative result

A fully in-class counterexample shows that the **global curvature product is arbitrarily conservative**.

Construct a regular \(C^1\) piecewise-cubic reference curve with:
- a straight first region;
- a later curved region whose maximum curvature \(K\) can be made arbitrarily large.

On the straight region, apply a small monotone piecewise-cubic tangential reparameterization supported away from the curved region, leaving the curved part unchanged. The reference and candidate have exactly the same image, so
\[
d_H=0.
\]
The synchronized error is purely tangential where it is nonzero, so
\[
N_{G,\perp}=0,
\qquad N_{G,\parallel}=A>0.
\]
Yet the global bound gives
\[
\frac K2A^2,
\]
which can be arbitrarily large because \(K\) comes from a remote region where the error is zero.

## What survived the attack

### Near-zero speed

A badly parameterized straight-line family with \(\min\|C'\|\to0\) still receives exact zero geometric error under the arc-length quotient. The exact monotonicity polynomial remains positive.

Conclusion: near-zero speed is primarily a numerical-conditioning hazard, not a mathematical contradiction.

### High curvature at the same location

The local expansion
\[
\gamma(s+\delta)=\gamma(s)+T\delta+\frac12\kappa_{\rm vec}\delta^2+o(\delta^2)
\]
shows that the quadratic curvature effect is geometrically real and asymptotically sharp. The problem is not curvature itself but using one remote global supremum.

### Short spans and double knots

No theoretical failure. They affect conditioning and require spanwise/one-sided treatment.

### Near self-approach

The method remains logically safe because it constructs an explicit order-preserving correspondence. But it behaves more like an upper bound through Fréchet distance than a Hausdorff-optimal correspondence. On order-ambiguous/self-near curves, the gap to Hausdorff can be large.

## Stage decision

**Do not write the TeX stage note yet.**

The core D2/Green framework survives, but the current global geometry-aware bound does not qualify as a practical final metric.

This is classified as a productive partial failure:
- theory is not wrong;
- the failure mechanism is explicit;
- it identifies exactly where locality was lost.

## New main direction

Two possible repairs:

1. localize curvature to the actual shifted arc interval;
2. replace the first-order shift by a nonlinear local normal correspondence.

The second route is preferred because it automatically restores locality and connects directly to Degen's normal-distance framework.
