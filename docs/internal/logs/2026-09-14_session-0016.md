# Session 0016 — Local covers replace mandatory global stitching

Date: 2026-09-14.

## Objective

Return from the Session-0015 Hausdorff side study to the active verification question:

> Do locally certified normal branches need to stitch into one global monotone correspondence before they can certify the symmetric Hausdorff distance?

Out of scope:
- candidate generation in \(q=C''\) space;
- global reach computation;
- exact nearest-point uniqueness;
- production implementation;
- a full Fréchet theory.

## Main result

For pure Hausdorff semantics, global stitching is stronger than necessary.

If source intervals \(T_i\) cover the source curve and each interval has any certified correspondence \(\sigma_i\) satisfying
\[
\|P(t)-Q(\sigma_i(t))\|\le\varepsilon_i,
\]
then
\[
h(P,Q)\le\max_i\varepsilon_i.
\]
No continuity or compatibility between adjacent local correspondences is required.

Repeating the same construction with source and target swapped gives
\[
d_H(P,Q)
\le
\max\{B_{P\to Q},B_{Q\to P}\}.
\]

Therefore a two-directed-pass local architecture is sufficient for a symmetric Hausdorff upper bound.

Detailed derivation:
`docs/internal/derivations/local_cover_hausdorff_certificate.md`.

## Important simplification

The orientation condition
\[
F_t>0
\]
was used only to guarantee an order-preserving local branch. It is not needed for the directed Hausdorff theorem.

For the two-pass Hausdorff architecture, the local admissibility primitive can therefore use only
\[
F(t,u_L)>0,
\qquad
F(t,u_R)<0,
\qquad
F_u<0.
\]

This is potentially important computationally because the previous feasibility experiment showed \(F_t\) becoming restrictive in higher-curvature boxes.

## Unexpected structural connection

The reverse normal equation is
\[
(Q(u)-P(t))\cdot P'(t)=0,
\]
which is exactly
\[
-G(t,u)=0
\]
for the Session-0014 common-normal polynomial
\[
G(t,u)=(P(t)-Q(u))\cdot P'(t).
\]

Thus the algebra used to find forward branch extrema is also the algebra of the reverse normal correspondence.

## Alternative one-pass route

A second reverse pass is not logically necessary if the union of forward branch images covers the entire target parameter domain. With orientation preservation, each branch image is an endpoint interval, so target coverage becomes an interval-union test.

This route may save one pass but keeps \(F_t\) and global coverage bookkeeping. The two-pass route is currently cleaner theoretically.

## Adversarial review

### Branch switching
Harmless for Hausdorff because each source point still has a target point within tolerance. It is only a problem for ordered/Fréchet semantics.

### Remote nearer branch
Harmless for an upper bound. A locally certified point need not be globally nearest.

### Target gaps
A genuine problem for a forward-only Hausdorff claim. The reverse pass or target-image coverage is required.

### Overlap / multiple coverage
Harmless.

### Double knots
No new global issue. Split reference windows at knots and use one-sided \(F_u\) signs. Source intervals may simply restart at source knots because branch equality is unnecessary.

### Self-intersection / traversal order
The two-pass theorem intentionally ignores order because Hausdorff does. If CAD semantics later require ordered traversal, restore the optional global Fréchet layer.

No counterexample to the local-cover theorem exists because it is an immediate consequence of the definition of directed Hausdorff distance. The real remaining uncertainty is computational usefulness, not logical validity.

## Correctness review

Confidence: **established**.

The one-sided and two-sided theorems are direct consequences of the definitions. The specialization to the current normal branch uses only already-established local existence/uniqueness and deviation bounds.

The claim that \(F_t\) is unnecessary is restricted explicitly to Hausdorff-only certification. It is not removed from the stronger ordered correspondence theory.

## Goal-alignment review

This materially improves the spline-simplification project rather than expanding it.

The previous roadmap risked turning the verifier into a global root-selection/topology problem. The local-cover theorem removes that requirement and keeps the geometry-aware layer local and fixed-degree.

The result also gives a precise role to Session 0015:
- Hausdorff is enough for final geometric acceptance;
- ordered correspondence is needed only when one wants differential/order semantics.

## Complexity review

The two-pass route roughly doubles local certification work, but removes:
- global branch interface matching;
- onto/homeomorphism proofs;
- mandatory orientation tests;
- global branch topology bookkeeping.

All remaining local polynomials have fixed degree for cubic-cubic boxes. This trade currently looks favorable, but must be tested.
