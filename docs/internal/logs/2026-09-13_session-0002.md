# Session 0002 — Exact D2 Reduction

Date: 2026-09-13

## Objective

Do **one** foundational task only: make the map from a \(C^1\) cubic spline to its piecewise-linear second derivative mathematically exact, and determine whether simplification of the PL object really corresponds to simplification of the cubic representation.

Do not study Green constants, normal projection, reparametrization, or algorithms in this session.

## Work performed

Defined the spaces
\[
S^1_3(\Pi;\mathbb R^d)
\]
and discontinuous piecewise-affine data
\[
PL_{\rm disc}(\Pi;\mathbb R^d).
\]

Proved that
\[
D^2:S^1_3\to PL_{\rm disc}
\]
is onto and
\[
\ker D^2=\mathcal P_1.
\]

Therefore
\[
S^1_3/\mathcal P_1\cong PL_{\rm disc}.
\]

Derived two ways to fix the affine kernel:
- initial position + initial derivative;
- two endpoint positions.

Then classified each essential PL singularity:
- jump in \(q=C''\) -> cubic is \(C^1\) but not \(C^2\) -> minimal multiplicity two;
- continuous kink in \(q\) -> cubic is \(C^2\) but not \(C^3\) -> minimal multiplicity one;
- neither -> breakpoint is redundant.

Defined
\[
\kappa(q)=K+2J
\]
with \(K\) kinks and \(J\) jumps, and checked
\[
N_{\rm ctrl}=4+\kappa(q)
\]
for a minimal open/clamped cubic representation.

A detailed proof was stored in `docs/internal/derivations/d2_reconstruction.md`.

## Successful result

The original conceptual reduction survives a strict review and is stronger than initially stated.

The important result is not merely

> cubic -> polyline after two derivatives,

but

> **minimal cubic knot multiplicity is encoded exactly by the singularity type of the PL second derivative.**

Therefore the D2-domain carries the fixed-degree representation complexity exactly.

## Failed attempts / rejected claims

No major false theorem was encountered.

One informal formulation was rejected/refined:

> "minimize the number of PL breakpoints"

is too crude. A discontinuous breakpoint corresponds to a double cubic knot and should count differently from a continuous kink if the objective is control-point / knot-multiplicity complexity.

Use \(\kappa=K+2J\), not raw unique breakpoint count, when discussing exact representation complexity.

## Unexpected issue / new idea

The proof exposed the affine kernel as a modeling choice rather than a technicality.

Because \(D^2\) removes affine functions, a q-domain metric has no positional meaning until reconstruction is gauged. Three possibilities are now visible:

1. fix position + tangent at one endpoint;
2. fix both endpoints (current CAD-preferred default);
3. optimize the affine correction after simplifying q.

Option 3 might tighten approximation when endpoint preservation is not required, but is parked.
