# Session 0017 — Bad parameterization and intrinsic candidate variables

Date: 2026-09-18.

## Objective

Evaluate two proposed routes motivated by the observed bad-parameter limitation of the Lyche/Lp branch:

1. simplify the derivative polyline geometrically in the \(C^1\) quadratic toy case, then integrate;
2. use intrinsic moving-frame quantities such as curvature/torsion instead of raw parameter derivatives.

Out of scope:
- no implementation;
- no replacement of the pending Phase-4 two-sided Hausdorff test;
- no full arc-length reparameterization algorithm.

## Main results

### 1. Derivative-image Hausdorff alone is insufficient

An explicit continuous-PL example has
\[
d_H(\operatorname{Im}C',\operatorname{Im}\widetilde C')=0
\]
but the integrated \(C^1\) piecewise-quadratic curves have Hausdorff distance \(1/4\).

Thus integration cannot be controlled by a setwise derivative-space Hausdorff error.

### 2. Coherent derivative approximation does integrate stably

If
\[
\|C'-\widetilde C'\|_\infty\le\varepsilon
\]
under one coherent parameter correspondence, then
\[
\|C-\widetilde C\|_\infty\le L\varepsilon.
\]
If both endpoints are shared, the bound improves to
\[
\|C-\widetilde C\|_\infty\le \frac L2\varepsilon.
\]

Therefore the useful quadratic toy problem is ordered/Fréchet-like derivative simplification, not pure derivative-image Hausdorff simplification.

### 3. Exact gauge/shape decomposition

For every regular curve,
\[
C''=v'T+v^2K,
\qquad
K=\frac{dT}{ds}
=\frac{P_{T^\perp}C''}{\|C'\|^2}.
\]

The tangential term \(v'T\) is pure parameter-speed complexity. A badly parameterized straight line can have arbitrarily complicated \(C''\) while \(K\equiv0\).

This is now a stable warning for Phase 5: raw \(q=C''\) mixes parameter complexity with shape complexity.

### 4. Intrinsic Bishop-frame stability

For arc-length curves with aligned initial point/frame and Bishop coefficients \((k_1,k_2)\), \((\widetilde k_1,\widetilde k_2)\), define
\[
\delta=\sqrt{(\Delta k_1)^2+(\Delta k_2)^2}.
\]
Then
\[
\|T(s)-\widetilde T(s)\|
\le
\int_0^s\delta(r)\,dr,
\]
and
\[
\|C(s)-\widetilde C(s)\|
\le
\int_0^s(s-r)\delta(r)\,dr.
\]
Hence
\[
d_H(C,\widetilde C)
\le
\frac{L^2}{2}\|\delta\|_\infty.
\]

This is a genuine parameter-invariant analogue of Green transport. Bishop variables are preferable to Frenet \((\kappa,\tau)\) near zero curvature.

## Interpretation

The quadratic derivative-polyline idea is useful as a toy model but does not fully quotient out speed. The intrinsic-frame idea is deeper and directly addresses the bad-parameter pathology, but loses the exact spline-complexity dictionary.

Two future bridges are recorded:
- geometry-preserving parameter gauge fixing before \(q\)-space simplification;
- intrinsic candidate generation followed by spline recovery and Hausdorff certification.

## Goal alignment

This session does not divert the project away from the current verifier. Instead it changes the design constraint for Phase 5:

> candidate generation must distinguish parameter complexity from geometric complexity before treating \(q=C''\) as the optimization variable.

The current Hausdorff verifier is complementary: it can certify candidates produced by either a parameter-domain or intrinsic-domain method.
