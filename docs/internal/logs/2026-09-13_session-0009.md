# Session 0009 — Local Normal-Branch Admissibility Certificate

Date: 2026-09-13

## Objective

Determine whether Degen-style admissibility can be turned into a cheap local certificate for cubic simplification pairs, without opening a global reach/nearest-point theory.

## Main result

For
\[
F(t,u)=(\widetilde C(t)-C(u))\cdot C'(u),
\]
on a candidate/reference box \(T\times U\), the conditions
\[
F(t,u_0)>0,\quad F(t,u_1)<0,\quad F_u<0
\]
certify one and only one normal root \(u=\sigma(t)\) for every \(t\in T\). The root is the unique local minimizer of squared distance over \(U\). If also \(F_t>0\), the branch is orientation preserving.

For cubic spans:
\[
\deg F\le(3,5),\qquad
\deg F_u\le(3,4),\qquad
\deg F_t\le(2,2),
\]
so tensor-product Bernstein sign tests give a direct certified route.

A sharper Green/Newton predictor was also identified:
\[
\sigma_N=t-\frac{E\cdot C'}{\|C'\|^2+E\cdot C''}.
\]

## Source connection

Degen's Definition 1 first imposes normal-field membership, uniqueness of correspondence, tangent transversality, and common endpoints; only afterwards does he define the deviation function and normal distance. Session 0009 turns part of that admissibility architecture into explicit polynomial sign tests specialized to cubic span pairs.

## Reality review

This result is useful only as a local fast path for already-close simplification candidates. It deliberately does not solve global self-approach or compute exact reach.

The next question is empirical: are these sufficient sign tests permissive enough on ordinary close cubic pairs? Continuing to sharpen the theorem before answering that would risk abstraction drift.
