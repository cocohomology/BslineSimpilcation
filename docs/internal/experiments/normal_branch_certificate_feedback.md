# 局部法向分支证书：编码实验反馈

实验日期：2026-09-14。对象：正则、保端点、非有理、三次 $C^1$ 分段样条。

需求依据：[normal_branch_certificate_test_plan.md](https://github.com/cocohomology/BslineSimpilcation/blob/main/docs/internal/experiments/normal_branch_certificate_test_plan.md)；数学解释依据：[局部证书推导](https://github.com/cocohomology/BslineSimpilcation/blob/main/docs/internal/derivations/local_normal_branch_certificate.md)。

## 1. 对研究目标的回答

**本次小规模实验支持把简单局部证书作为普通近邻候选的快速认证途径，值得进入下一阶段；没有证据支持先加强可容许性理论。Newton 预测器的显著优势则没有得到支持。**

普通五类共有 60 对曲线、400 个原始候选区间；两种预测器分别运行，共 800 次区间试验。最终 800/800（100.00%） 通过；其中 799/800（99.88%） 在最大细分深度 0–2 内通过，只有一个低速、删减节点的区间需要深度 3。小法向、切向、混合三类全部不细分即通过。

近自接近负对照有 12 对曲线、80 个区间，两预测器合计 160 次试验，124 次通过、36 次回退。所有基线回退都集中在这一类。与此同时，部分已认证的局部法向足点仍不是全曲线最近点，这正是该证书的适用边界。

这里的“通过”是局部对应的存在、唯一、方向保持的认证，不是候选已经满足某个给定几何公差；本次没有给定公差，也没有求隐式分支上的最大偏差。

## 2. 测试数据及覆盖范围

共 72 对确定性曲线，六类各 12 对。每类是四档扰动强度与三种节点配置的组合。每个参考曲线有 8 段；候选分别保留 8 段、删减为 4 段、移动内部节点但仍保留 8 段。总计 480 个原始候选区间。两预测器属于同一样本的配对比较，因此 960 次试验不能解释为 960 个独立随机样本。

| 类别 | 构造与目的 |
| --- | --- |
| 小法向扰动 | 温和空间曲线，沿参考切向的正交方向施加小扰动，检查基本近邻情形。 |
| 轻微切向重参数化 | 以 $w(t)=t+\beta\sin(2\pi t)/(2\pi)$ 取参考点，检查同参数位移较大而几何改变较小的情况。 |
| 法向＋切向混合 | 上述重参数化叠加法向扰动，接近实际候选同时存在两类误差的情形。 |
| 非均匀速度／短区间 | 参考速度由 $g(t)=0.03t+0.97t^3$ 控制，近直线参考几何；包含长度 $1/1024$ 的短区间，候选叠加扰动和重参数化。 |
| 较大曲率 | 增大参考曲线横向起伏和空间起伏，使窗口中的切向变化明显；叠加小法向扰动。 |
| 近自接近负对照 | 平面发夹形曲线，两臂接近、名义间隔尺度 0.02，向另一臂施加位移；包含急弯与多法向根风险。 |

法向扰动名义幅值为 0.0002、0.001、0.003、0.008，沿参数乘以 $\sin(\pi t)$ 保持两端位置；切向参数 $\beta$ 为 0.01、0.03、0.06、0.12。负对照位移幅值为 0.007、0.012、0.018、0.024。参数域统一为 [0,1]，主要几何长度尺度约为 1。

上述光滑构造用于指定节点位置和切向，再形成真正的分段三次候选。因三次重建和节点变化，标签“法向／切向”描述的是构造来源，不表示整个区间上严格只有法向误差，也不表示一般的非线性复合曲线仍恰为三次。删减节点案例确实从 8 段降至 4 段，但不是由某个已完成的简化优化器产生。

普通参考节点为 0、1/8、…、1；短区间参考节点为 0、1/1024、1/64、1/8、1/4、1/2、3/4、7/8、1。删减后的节点为 0、1/4、1/2、3/4、1；移动后的节点为 0、3/32、7/32、11/32、17/32、23/32、27/32、29/32、1。

所有 72 对存储后的曲线均验证了公共端点；912 处内部连接以精确有理数检查了位置和一阶导数相等。允许且实际包含二阶导数跳跃。所有参考／候选区间都获得了严格大于零的速度分量包围下界，因此正则性不是仅依靠采样判断。

## 3. 试验设置与通过口径

固定候选区间 $T$，分别用 $\sigma_0$ 与 $\sigma_N$ 估计附近参考参数范围。初始范围使用 9 个等距预测点，并补充跨参考节点处的二阶导数单侧信息；两侧各加 $0.125|T|$ 的余量，裁剪到 [0,1]。这只是选窗启发式，预测采样不承担任何认证作用。

检查 $F(t,u_L)>0$、$F(t,u_R)<0$、$F_u<0$、$F_t>0$。若边界符号未获认证，每个当前子问题最多向两侧各扩展 $0.25|T|$ 一次；仍不通过则二分候选区间，对子区间重新选窗，最大深度 4。参考窗口只在已有参考节点处分片，没有为追求通过而展开全局二维搜索。

“深度 0”允许一次上述扩窗，因此表示不细分成功，不必然等于第一次窗口就成功。不过基线普通五类没有发生扩窗，所以这些类别的深度 0 确实就是初始窗口直接通过。

原始区间只有在全部子区间通过时才记为通过，深度记所需的最大二分深度；任何子区间到达上限仍不通过，整个原始区间记为回退。二分深度 2 最多形成 4 个叶区间，深度 4 最多 16 个；深度不是累计切分次数。回退区间中已成功的局部叶区间仍参与局部验证，但不抬高原始区间通过率。

### 公共端点的必要处理

由于保端点，$F(0,0)=F(1,1)=0$；在闭参数域上直接要求所有边界严格异号，会必然排除含全局端点的区间。基线对已精确确认的公共端点允许该唯一端点的 Bernstein 系数为零，要求其余边界系数严格同号，且仍要求整个窗口的 $F_u<0$、$F_t>0$。这证明端点以外严格异号，端点本身对应公共端点；不是把任意接近零的数放宽为通过。

另行运行了完全照字面要求闭区间严格边界符号的版本：通过数由 924 降至 636，恰好少 288 次，即 72 对 × 两个全局端点区间 × 两预测器。该差异是端点公式的结构性限制，不是近邻曲线质量差。基线结论因此应准确称为“带公共端点特例的证书”结论。

## 5. 失败来自哪些条件

下表统计每次尝试中未获认证的条件，包含后来细分成功的父区间、扩窗前后的重复尝试。一个尝试可同时失败于多个条件，因此各列不能相加作为失败区间数，也不能当作独立事件概率。

| 类别 | 左边界 | 右边界 | $F_u$ | $F_t$ |
| --- | --- | --- | --- | --- |
| 小法向扰动 | 0 | 0 | 0 | 0 |
| 轻微切向重参数化 | 0 | 0 | 0 | 0 |
| 法向＋切向混合 | 0 | 0 | 0 | 0 |
| 非均匀速度／短区间 | 0 | 0 | 139 | 0 |
| 较大曲率 | 0 | 0 | 216 | 48 |
| 近自接近负对照 | 148 | 124 | 505 | 207 |

非均匀速度组的障碍全部来自 $F_u$。即使实际法向根附近是良态的，整块参数矩形仍可能包含足够大的切向分离，使距离与加速度项妨碍统一负号。较大曲率组还出现 $F_t$ 障碍，表明窗口内切向方向变化需要通过缩小窗口处理。

负对照同时出现边界、$F_u$、$F_t$ 障碍；它不是一个只靠多加一点窗口余量就能稳定解决的情形。这里统计的是“充分条件没有通过”，没有声称每次失败都证明对应分支不存在，也没有把 Bernstein 包围不确定与真正的反号逐一分离。

初始宽度比为 $|U|/|T|$；最终宽度比对叶区间按候选参数长度加权，即 $\sum |U_{leaf}|/|T_{original}|$。表中再对原始候选区间取算术平均，回退叶也计入；它不是所有参考窗口并集的长度。

普通类别的窗口平均宽度仅为当前候选区间的约 1.21–1.23 倍，保持局部性。近自接近组初始平均约 1.74 倍，最终约 1.91／1.95 倍；个别初始比达到 5.12、最终加权比达到 6.39，明显暴露了该负对照的选窗困难。

两预测器的基线最终通过数相同，都是 462/480；绝大多数区间的最大深度相同。Newton 仅在 ID 46 的一个区间把深度 3 降到 2，平均窗口并未稳定缩小。负对照的 Newton 分母在 68 个预测求值点不满足正性保护条件，改用一阶预测；这是预测点计数，不是 68 条曲线。普通五类没有触发这一保护。

**结论：不能宣称 Newton 显著减少窗口或细分。** 当前证据支持保留简单一阶预测作为默认基线，把 Newton 当作可选比较项。是否值得使用 Newton，需要在更广的样本或不同选窗策略下再看，而不是从其公式更精确就推断工程收益。

## 7. 独立验证与可信度

基线共核对 28,645 次参数点，其中 26,860 次属于已认证叶区间。核对过程独立求各参考三次段的法向方程根，与证书窗口内的二分根比较，同时把所有参考段的根和全局端点纳入距离比较。共享叶端点及两种预测器会重复计数，不能把这些次数当作独立几何点数。

| 核对项 | 基线结果 |
| --- | --- |
| 已认证叶上的根数／根位置不一致 | 0 |
| 叶内方向逆转 | 0 |
| 同一原始区间内相邻已认证叶的接缝不一致 | 0 |
| 认证根与全曲线法向根中参数最接近 t 者不一致 | 0 |
| 最大参数根差 | 9.333e-13 |
| 最大归一化法向残差 $\|F\|/\\|C'\\|$ | 5.478e-16 |
| Green 重建与直接差的最大残差 | 2.316e-16 |

把每个叶区间验证点从 17 增加到 65 后，共核对 109,525 次，其中已认证叶 102,700 次，仍没有上述不一致，认证率保持不变。抽样求根是数值核对，不是连续参数上的全局最近点证明，也没有建立整条曲线跨所有原始区间的全局对应定理。

此外，基线全部 **1580 个已认证叶、3121 个跨参考段子矩形** 都用独立的精确有理数运算重新检查了四类 Bernstein 符号。该复核从存储后的曲线和窗口出发重新形成多项式，没有依赖浮点证书的判定结果作为数学依据；零项严格按公共端点处理。全部通过。因此基线的符号成功不是由舍入误差误判出来的。该精确复核是实验可信度检查，不属于拟议快速路径的成本。

### 近自接近负对照揭示的边界

普通五类没有观察到远处参考曲线比所选局部足点更近。负对照中，基线有 **2,925 次已认证叶上的抽样核对** 发现更近的全曲线点，最大距离改善约 0.012816。这里把距离改善大于 $10^{-7}$ 计为明确差异；两预测器和共享端点仍会重复计数。

这不是局部证书的反例：窗口内根仍唯一、局部最小、保持方向，而且与独立求根一致；只是另一条靠近的曲线臂可以提供更短距离。负对照因此同时验证了“困难处会回退”和“局部通过不能排除远处分支”两件不同的事。不能把负对照全部通过／全部失败当作正确性标准。

基线所有叶（含回退叶）的数值核对还记录了 91 次窗口内多根、917 次窗口内无根，都没有发生在已认证叶上；这些主要用于解释回退，不是对整个参数域的根数证明。

| 能否据此代替全局最近点／Hausdorff | 不能。负对照明确观察到局部认证正确、但远处更近。 |

建议维持当前局部充分条件，进入 roadmap 中沿已认证隐式分支判断公差的下一小步；继续保留同步 Green 上界及一般验证作为回退。若需要限定很低的细分预算，深度 2 已覆盖本批绝大多数普通案例。公共端点特例需要在后续数学表述中明确保留。

这个判断只适用于本批结构化合成样本。实验没有随机抽样总体、真实 CAD 数据或优化器输出，没有给出统计置信区间，也未测量工程速度。因此不能外推工业通过率或宣称比 Hausdorff 算法快多少。尚未覆盖近奇异但仍正则的更多形态、尺度变化、闭合／周期曲线和更复杂的多重自接近。它完成的是研究可行性关口，而非生产算法验收。
