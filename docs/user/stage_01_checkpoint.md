# Stage 01 Checkpoint — What the First Theory Cycle Actually Established

Date: 2026-09-13

This document is a user-facing checkpoint for re-entry after the first theory cycle. It is intentionally shorter than the internal stage review and avoids transient branches.

## Starting question

The working hypothesis was that a regular C1 cubic spline may be easier to simplify after differentiating twice:

\[
C\mapsto q=C'',
\]

because q is piecewise linear. The hope was that representation complexity, approximation error, and geometry might all become more transparent in this derivative domain.

That hypothesis has survived its first serious review, but only in a layered form.

## What is now on firm ground

For regular C1 piecewise cubics,

\[
D^2:S_3^1\to PL_{\rm disc}
\]

is onto with affine kernel. Kinks and jumps of q=C'' encode simple and double cubic knots, so the derivative domain carries the cubic representation complexity exactly.

Under the current endpoint-preserving gauge,

\[
E=C-\widetilde C=G_D(C''-\widetilde C''),
\]

so the Green operator gives the exact synchronized positional error. Because the error curve E is itself piecewise cubic, its max norm can be certified using only fixed-degree one-variable polynomial problems or cubic Bézier subdivision.

This already yields a useful baseline architecture: simplify in the PL second-derivative domain, then certify the resulting synchronized position error without falling back to dense sampling or a loose global Lp estimate.

## What was learned about parameterization

The synchronized error is parameter-sensitive, but its tangent/normal decomposition has a clear first-order interpretation: tangent displacement is the infinitesimal reparameterization direction, while normal displacement is the first-order geometric residual.

An initial global curvature correction was mathematically valid but was shown by an explicit cubic C1 counterexample to be arbitrarily conservative when large curvature is remote from the tangential error. This result is treated as a boundary of that specific global formula, not as a failure of the derivative-domain program.

## Why Degen became relevant

Re-reading Degen suggested that a good geometry-aware distance should not begin by guessing a norm. One should first define an admissible geometric correspondence and only then measure the deviation.

This led to the nonlinear normal equation

\[
(\widetilde C(t)-C(u))\cdot C'(u)=0.
\]

The previous first-order tangent correction turned out to be exactly the Newton / implicit-function linearization of this nonlinear equation, so the earlier analysis fits naturally into the refined picture.

## Current geometry-aware fast path

For one candidate cubic span T and a nearby reference window U=[u0,u1], define

\[
F(t,u)=(\widetilde C(t)-C(u))\cdot C'(u).
\]

If

\[
F(t,u_0)>0,\qquad F(t,u_1)<0,\qquad F_u(t,u)<0
\]

throughout the local box, then every candidate point in T has exactly one normal foot in U, and that foot is the unique local distance minimizer inside U. If also

\[
F_t(t,u)>0,
\]

the resulting branch is orientation preserving.

For cubic span pairs the relevant bivariate polynomials have fixed low bidegrees, so Bernstein sign tests and local subdivision offer a plausible certified implementation route.

The synchronized Green error provides a cheap predictor for where the normal root should lie, including the one-step Newton estimate

\[
\sigma_N(t)=t-
\frac{E\cdot C'}{\|C'\|^2+E\cdot C''}.
\]

## Current architecture

The most useful way to view the first stage is now:

\[
\boxed{
\text{PL second-derivative representation}
\to
\text{exact Green synchronized error}
\to
\text{optional local normal correspondence}
}
\]

The first layer handles complexity. The second gives a cheap rigorous baseline certificate. The third is only a local fast path for obtaining a tighter geometry-aware correspondence when the curves are already close.

No attempt is currently being made to turn the third layer into a universal global nearest-point theory.

## Why theory is pausing here

The unresolved question is now empirical rather than formal:

> On ordinary close cubic pairs generated by simplification, do the simple local Bernstein sign tests usually certify the intended normal branch with little or no subdivision?

A small feasibility experiment has therefore become the next gate. If ordinary cases pass cheaply, the geometry-aware layer deserves further development. If they do not, the project should not respond by building a much heavier admissibility theory; it should simplify the architecture.

## TeX note decision

A full user-facing TeX note is **deferred**.

The current theory is substantial enough to justify this checkpoint, but not yet stable enough to freeze into a polished note. The local normal-branch certificate has not passed its numerical feasibility gate, and the actual low-complexity candidate-generation problem in q-space has not yet been designed.

The first TeX note should be written after either:

- the feasibility experiment validates the local geometric layer and a second adversarial review confirms the resulting pipeline; or
- the experiment rejects that layer but leaves a coherent negative/boundary result worth preserving as a completed stage.

When that note is eventually written, it should be self-contained and include a short Green-function/Green-kernel introduction rather than assuming that background.

## What remains open after Stage 01

The immediate next step is the feasibility experiment. Beyond it, the largest untouched problem is candidate generation: how to approximate the complicated PL function q=C'' by a much lower-complexity PL function while respecting the chosen error certificate.

Several theoretical branches have been deliberately parked rather than discarded—localized curvature remainders, optimized affine reconstruction, shape-space interpretations, symmetric certification, lower-continuity distributional extensions, and free-breakpoint PL approximation. They are recorded internally with explicit conditions for when they should be reopened.
